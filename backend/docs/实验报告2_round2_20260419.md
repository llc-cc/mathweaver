## 四、典型案例分析

### 4.1 两者都错的案例

#### 案例11: prop_03_不共面三向量线性无关性

**原始命题:** 几何空间中,不共面的三个向量是线性无关的。

**方式1输出:**
```lean
theorem test_theorem {K : Type*} [Field K] (α β γ : Fin 3 → K)
  (h : ¬∃ (a b c : K), a • α + b • β + c • γ = 0 ∧ (a ≠ 0 ∨ b ≠ 0 ∨ c ≠ 0) → False) :
  LinearIndependent K ![α, β, γ]
```

**问题:** 不共面不等于线性无关。形式化用了双重否定。

**方式2输出:**
```lean
theorem test_theorem {K : Type*} [Field K] (α β γ : Fin 3 → K) :
  (¬∃ (a b : K), α = a • β + b • γ ∨ β = a • α + b • γ ∨ γ = a • α + b • β) →
  LinearIndependent K ![α, β, γ]
```

**问题:** 不严谨，三个向量互相不在另外两个张成的平面内 ≠ 线性无关。

---

#### 案例34: prop_22_向量组线性无关与秩的关系

**原始命题:** 向量组线性无关的充分必要条件是它的秩等于它所含向量的个数。

**方式1/2输出:**
```lean
LinearIndependent K α ↔ Matrix.rank (Matrix.of α) = s
```

**问题:** Matrix.rank是矩阵的秩，与向量组的秩（子空间维数）不同。正确应用Module.rank或Submodule.span.card。

---

### 4.2 仅方式1错的案例

#### 案例27: prop_17_向量线性表出与极大线性无关组

**原始命题:** 2β可以由向量组线性表出当且仅当β可以由该向量组的一个极大线性无关组线性表出。

**方式1输出:**
```lean
(∃ (c : Fin s → K), 2 • β = ∑ i, c i • α i) ↔ ...
```

**问题:** 左边是2•β而不是β，完全改变了命题含义。

**方式2输出:**
```lean
(∃ (c : Fin s → K), 2 • β = ∑ i, c i • α i) ↔ ∃ (I : Finset ...), ...
```

**评价:** 虽然2•β看起来奇怪，但M2更完整地表达了命题结构。

---

### 4.3 仅方式2错的案例

#### 案例21: prop_11_等价关系的反身性

**原始命题:** 任何一个向量组都与自身等价。

**方式1输出:**
```lean
theorem equivalence_relation_reflexivity ... :
  (∀ i, α i = α i)
```
**问题:** 只证明了恒等式，没有表达等价关系。

**方式2输出:**
```lean
theorem reflexivity_of_equivalence_relation ... :
  ∃ (T : Set ...), α ∈ T ∧ ∀ β ∈ T, ...
```
**问题:** 编译失败，且语义上也不正确。

**结论:** 方式1更接近正确（虽然语义仍不完整），方式2完全错误。

---

### 4.4 上下文不当案例

#### 案例16: K^n中的标准基

**原始命题:** 标准基向量组是线性无关的且可以张成整个空间。

**方式1输出:**
```lean
theorem standard_basis_vectors :
  ∀ (K : Type*) [Field K] (n : ℕ),
  ∃ (ε : Fin n → Fin n → K),
    (∀ i j, ε i j = if i = j then 1 else 0)
```

**问题:** 只证明了存在性，没有证明线性无关和张成性。

**方式2输出:**
```lean
def standardBasis (K : Type*) [Field K] (n : ℕ) : Fin n → Fin n → K :=
  fun i j => if i = j then 1 else 0
theorem test_theorem ... :
  LinearIndependent K (standardBasis K n) ∧
  Submodule.span K (Set.range (standardBasis K n)) = ⊤
```

**评价:** 方式2完整表达了命题，方式1缺失关键性质。

## 六、提示词修改建议

### 6.1 可通过提示词解决的

**问题:** 不共面/不共线向量误判为线性无关

**建议提示词补充:**
```
注意：在n维空间中，n个向量线性无关的充分必要条件是它们张成的子空间维数为n。
不共面（对于3维）只是一个特殊的几何性质，不能直接推出线性无关。
请明确定义"不共面"的数学含义。
```

**问题:** Matrix.rank vs Module.rank

**建议提示词补充:**
```
对于向量组的秩，应使用Module.rank或Submodule.span的维数，
不要使用Matrix.rank（这是矩阵秩，与向量组秩不同）。
```

### 6.2 难以通过提示词解决的

| 问题类型 | 案例 | 原因 |
|----------|------|------|
| 语义理解错误 | 37 | 相等向量组必等价是数学事实，模型误解了原命题 |
| 过度构造 | 24 | 模型将定义性命题误当作需要证明的命题 |

## 七、结论

### 7.1 主要发现

1. **编译成功率都很高**: 方式1 (95.2%) vs 方式2 (92.9%)

2. **语义正确率相近**: 方式1 (57.1%) vs 方式2 (61.9%)

3. **方式2的优势:**
   - 提供更多上下文有助于理解复杂命题
   - 标准基等定义性问题表达更完整

4. **方式1的优势:**
   - 简单直接，减少上下文干扰
   - 编译失败率更低

5. **共同问题:**
   - 几何直觉与代数概念混淆
   - API选择不当（Matrix.rank误用）
   - 缺乏对蕴含vs等价关系的区分

### 7.2 建议

1. **优化提示词:** 明确区分等价关系(↔)和蕴含关系(→)
2. **增加API指导:** 强调使用Module.rank而非Matrix.rank
3. **添加几何约束:** 对于n维空间，明确n个向量线性无关的充分必要条件
4. **保持简单:** 对于简单命题，优先使用方式1
