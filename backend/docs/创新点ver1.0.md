Core Concept
1、逻辑致密化
现有单文档证明蓝图提取主要关注节点骨架和边，而忽视了自然语言数学中普遍存在的逻辑压缩现象。
 我们提出将“命题逻辑致密化”作为独立中间任务，系统识别并显式化：
 变量范围缺失 
 隐式定义依赖 
 局部条件作用域 
 中间推理省略 
 复合对象缺失 
方法论：采用“两个layer➕规则修复”，提升形式化质量
2、依赖提取规则 & “符号表 / 全局上下文传播”
单文档项目的独特方法点：
-  一整本书里有默认假设 
-  有整本书的符号表 
-  有章节级的定义环境
一个可能的包装：
我们在单文档层面维护符号表与全局上下文，使得节点致密化不是孤立做的，而是受文档级约束驱动。
这会明显区别于单条 theorem 的工作
