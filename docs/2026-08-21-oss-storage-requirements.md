# MathWeaver OSS 文件持久化需求

> 日期：2026-08-21<br>
> 状态：已确认，直接实施<br>
> 基线：`61a625f` / `pre-oss-20260821`

## 1. 目标

在不新增业务页面、不改变现有登录和任务接口的前提下，为 MathWeaver Web 版增加阿里云 OSS 文件持久化。MySQL 继续保存账号、会话、设置、任务状态、图谱结果和证明工作区；OSS 只保存需要跨服务器保留的用户文件。

## 2. 存储边界

### 2.1 MySQL

- 用户学号、邮箱、密码哈希、角色和启用状态；
- 登录会话与用户设置；
- 任务状态、阶段、节点、边、源 Markdown 和错误状态；
- 证明工作区；
- 每个任务对应的 OSS 对象前缀。

### 2.2 OSS

- 登录用户提交任务时生成的受控任务目录，包括输入文件、节点/边结果和可恢复阶段缓存；
- TeX 源文件、编译后的 PDF 和编译日志；
- 不保存账号、密码、会话令牌、模型密钥、数据库连接串、OCR 模型和临时工作目录。

匿名任务与桌面兼容模式继续使用本机临时目录，不上传 OSS。

## 3. 对象命名与隔离

所有对象必须位于部署配置指定的项目根前缀下，默认根前缀为 `mathweaver/`。任务对象前缀固定为：

```text
mathweaver/users/{user_id}/jobs/{job_id}/
```

子目录：

```text
artifacts/{任务目录相对路径}
source-pdf/{PDF、TeX、日志文件名}
```

- `user_id` 只能来自服务端已认证会话；
- `job_id` 必须通过安全字符校验；
- 对象名不得接受客户端提供的绝对路径或 `..`；
- 不跟随符号链接，不上传 `_stage_work` 和 `*.tmp`；
- 不生成永久公开 URL，下载仍通过现有鉴权接口完成。

## 4. 生命周期

### 4.1 保存

- 新任务首次持久化前，上传已写入的输入文件；
- 每个阶段完成、任务暂停、失败或完成时，将受控任务目录和源 PDF 目录同步到 OSS；
- OSS 同步成功后才允许 MySQL 将对应状态标记为已安全持久化；
- OSS 失败时返回统一的持久化错误，日志不得包含 AccessKey Secret。

### 4.2 恢复与下载

- 任务恢复、处理产物下载或源 PDF 访问发现本地文件缺失时，从该用户自己的 OSS 前缀恢复；
- 恢复目标必须位于受控数据目录内；
- 其他用户访问同一任务 ID 时仍返回 404，不触发任何 OSS 下载。

### 4.3 删除

- 用户删除历史任务或取消已暂停任务时，同时删除该用户任务前缀；
- 删除操作只能使用服务端查询出的用户 ID 和任务 ID；
- 删除其他前缀或整个 Bucket 不在应用权限和代码能力范围内。

## 5. 配置与安全

后端从运行环境读取以下配置，真实值不得进入 Git、镜像构建参数、前端代码或日志：

```text
MATHWEAVER_OBJECT_STORAGE=oss
MATHWEAVER_OSS_ENDPOINT=
MATHWEAVER_OSS_BUCKET=
MATHWEAVER_OSS_ACCESS_KEY_ID=
MATHWEAVER_OSS_ACCESS_KEY_SECRET=
MATHWEAVER_OSS_PREFIX=mathweaver/
```

- Endpoint 必须使用 HTTPS；
- Bucket 必须为私有读写；
- RAM 用户只授予目标 Bucket 中 `mathweaver/*` 的列举、读、写和删除权限；
- 应用启动时配置不完整必须失败，不能悄悄退回本地持久化；
- 未启用 OSS 时保持原有本地/桌面行为，便于开发和兼容旧版本。

## 6. 兼容性

- 前端接口和页面保持不变；
- 已有 MySQL 历史记录允许 OSS 前缀为空，仍按旧本地逻辑读取；
- 新增数据库迁移只增加可空的对象前缀字段，不修改已有数据；
- 当前单机运行模型保持不变，不在本次引入多 Worker 协调或队列。

## 7. 验收标准

- OSS 配置校验、路径隔离、同步、恢复、删除均有自动化测试；
- 新任务的 MySQL 记录包含项目隔离的 OSS 前缀；
- 删除本地任务目录后，恢复/导出仍能从 OSS 取回所需文件；
- 用户 A 无法读取、恢复或删除用户 B 的对象；
- OSS 故障不会把任务误报为持久化成功；
- 前端测试、类型检查、构建和 OSS 相关后端测试通过；
- 使用生产 Bucket 做一次临时对象上传、读取、删除冒烟验证，验证对象最终不存在。

## 8. 非目标

- 老师端班级看板；
- OSS 公网直传和永久公开链接；
- 历史本地文件批量迁移；
- OCR 模型、运行时缓存和容器镜像存储；
- CDN、生命周期归档和跨地域复制。
